# 雨天旅行备选方案设计

## 适用场景

适合用户询问“日本下雨怎么办”“旅行遇到坏天气怎么调整”“带父母孩子雨天有什么备选”。本文不预测实时天气，也不承诺某室内场馆开放。天气预报、交通运行、景点开放和预约规则请以实时信息与官方渠道为准。

## 核心建议

雨天备选不要等下雨当天才想。每个城市至少准备三类备选：室内文化场馆、商业综合体或地下街、轻松餐饮休息。室内文化场馆适合博物馆、美术馆、水族馆、展览，但要提前查闭馆日和预约。商业综合体适合购物、餐饮、补给和短暂停留。餐饮休息适合把原本高强度户外日改成慢节奏恢复日。

行程设计上，把户外景点按“可雨中进行”和“不适合雨中进行”分类。神社寺庙、花园、观景台、海边、山路和长距离 citywalk 在雨天体验可能明显下降。家庭旅行遇雨时，优先减少换乘和步行，保留一项主活动即可。携带轻便雨具、防水鞋或备用袜子，比临时购买更从容。

回答用户时可以给出调整逻辑：先看安全，再看交通，再看体验价值。若雨势大或有强风，取消户外不是失败，而是保护同行人的体力和情绪。

## 风险提醒

雨天会增加滑倒、迷路、迟到、行李受潮和儿童疲劳风险。交通可能延误，热门室内场所也可能拥挤。实时天气、灾害提醒、交通运行和场馆开放请以官方渠道为准。
